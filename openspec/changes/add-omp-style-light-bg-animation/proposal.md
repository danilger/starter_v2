# Proposal

## Why

Нужна фоновая анимация в духе [omp.sh](https://omp.sh/) на текущем белом фоне приложения. Сейчас `starter_v2` — плоский светлый shell без декоративного фона; пользователь хочет тот же визуальный характер (pixelated stencil/poster + живой слой + scanlines), плюс медленную плавную смену цвета от розового к красному на всех страницах.

## What Changes

- Добавить полноэкранный декоративный фон в стиле omp.sh (dual-canvas poster + анимированный слой + scanlines), встроенный в общий app-shell, чтобы он был виден на всех маршрутах.
- Сохранить белый фон приложения (`--background` / body) как базовый слой; анимация лежит поверх него декоративно и не перекрывает взаимодействие с UI.
- Сохранить форму и характер палитры референса (дуга/«линза», sky/violet/plum/silver/black-семейство), адаптировав композицию под светлый фон без смены «характера» на монохром.
- Сохранить ориентацию референса (`scaleY(-1)`).
- Добавить медленную плавную циклическую смену hue/tint анимации в диапазоне от розового к красному.
- Учитывать `prefers-reduced-motion: reduce` (статичный кадр без анимации цвета/движения).
- Fidelity A: максимально близко к omp (canvas poster + GPU-анимация при наличии WebGPU, CPU fallback, scanlines) — не упрощать до «атмосферного» CSS-glow.

## Capabilities

### New Capabilities
- `omp-style-bg-animation`: app-wide фоновая stencil/poster-анимация в стиле omp.sh на белом фоне со медленным pink→red цветовым циклом и reduced-motion fallback

### Modified Capabilities

## Impact

- Код: `src/App.tsx` (или общий layout-wrapper вокруг nav + routes), новый компонент/модули под `src/components/` и/или `src/lib/` для canvas poster, GPU/CPU рендера и hue-цикла; возможно лёгкие правки `src/index.css` для stacking/scanlines.
- Зависимости: предпочтительно без тяжёлых новых UI-библиотек; допустим отдельный WebGPU/WGSL модуль (как у omp) или эквивалентная реализация в репо. CPU `ImageData` fallback обязателен, если GPU недоступен.
- Перфоманс: даунскейл canvas под бюджет пикселей; `pointer-events: none`; UI остаётся читаемым и кликабельным.
- Внешние сайты: референс omp.sh только как визуальный/технический ориентир — ассеты с omp.sh не hotlink-ить в проде.

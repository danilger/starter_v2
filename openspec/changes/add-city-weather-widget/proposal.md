# Proposal

## Why

Нужна страница с интерактивным виджетом текущей погоды: пользователь выбирает город из полного списка с поиском на клиенте и видит актуальные данные, которые обновляются каждые 5 секунд. Сейчас в `starter_v2` есть только Home/About/Calculator — weather-страницы и интеграции с внешними источниками нет.

## What Changes

- Добавить маршрут и страницу виджета погоды с пунктом в главной навигации.
- Подключить бесплатный открытый источник **полного списка городов** (отдельно от погоды); combobox загружает список и выполняет **клиентский** поиск/фильтрацию.
- Подключить **Open-Meteo** для текущей погоды по координатам выбранного города.
- Поллить текущую погоду с интервалом **5 секунд** после выбора города; показывать loading/error и время последнего успешного обновления.
- Отображать только **текущую** погоду (без forecast).

## Impact

- Код: `src/App.tsx` (маршрут и nav), новая страница под `src/pages/`, модули данных/типов под `src/lib/`, возможно UI combobox под `src/components/` (shadcn Command/Popover или аналог).
- Внешние зависимости: Open-Meteo Forecast API (погода); отдельный бесплатный датасет/источник городов (GeoNames-derived list) с полями имя, страна, lat/lon.
- Стек без обязательных новых runtime-библиотек сверх уже используемых React/Vite/Tailwind/shadcn; допустимо добавить shadcn-компоненты для combobox.
- Язык UI: русский (как в исходном запросе).
